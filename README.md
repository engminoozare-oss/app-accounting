# حساب کتاب — ثبت و تفکیک هزینه‌ها

برنامه‌ای ساده و فارسی برای ثبت هزینه‌های روزمره و دیدن اینکه **هر مرغداری و هر شخص چقدر خرج کرده است**.
روی **اندروید** و **ویندوز** نصب می‌شود، بدون اینترنت کار می‌کند و اطلاعات فقط روی همان دستگاه ذخیره می‌شود.

---

## چه‌کار می‌کند

- ثبت هزینه با **مبلغ، موضوع (بابت)، تاریخ شمسی، دسته‌بندی و توضیحات**
- تفکیک هزینه‌ها بین موجودیت‌های از پیش تعریف‌شده:
  - **مرغداری‌ها:** مرغداری دشت سبز، مرغداری بنافت
  - **کارگرها:** کارگر مرغداری دشت سبز، کارگر مرغداری بنافت
  - **مدیریت:** حسین (پدر)، ابوالفضل، امیر
- جمع کل و تفکیک بر اساس **موجودیت**، **دسته‌بندی** و **ماه شمسی**
- جدول متقاطع «موجودیت × دسته‌بندی» برای دیدن دقیق اینکه هر کس بابت چه چیزی چقدر خرج کرده
- فیلتر و جست‌وجو بر اساس دوره (این ماه / ماه قبل / امسال / همه / بازه دلخواه)، شخص و دسته‌بندی
- ویرایش و حذف هزینه‌های ثبت‌شده
- خروجی **CSV** (باز می‌شود در اکسل) و **چاپ / PDF**
- **همگام‌سازی بین دستگاه‌ها** (اختیاری): هزینه‌ی واردشده روی یک گوشی، روی گوشی‌ها و
  کامپیوتر دیگر هم دیده می‌شود
- **پشتیبان‌گیری و بازیابی** با فایل، برای انتقال بین گوشی و کامپیوتر
- تقویم شمسی، اعداد فارسی، و نمایش مبلغ به حروف هنگام ورود (برای جلوگیری از اشتباه در صفر)
- تم روشن و تیره به‌صورت خودکار

مرغداری‌ها، اشخاص و دسته‌بندی‌ها همه از بخش **تنظیمات** قابل افزودن، تغییر نام و حذف هستند.

---

## نصب

برنامه پس از هر تغییر روی شاخه `main` به‌صورت خودکار روی این نشانی منتشر می‌شود:

```
https://engminoozare-oss.github.io/app-accounting/
```

### یک‌بار برای همیشه: فعال کردن انتشار

۱. کد این شاخه باید در `main` باشد (بدون آن، فقط فایل README منتشر می‌شود).
۲. در گیت‌هاب: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
۳. در **Actions** منتظر بمانید تا اجرای «انتشار برنامه روی GitHub Pages» سبز شود (حدود یک دقیقه).

اگر نشانی بالا را باز کردید و به‌جای برنامه، متن README را دیدید، یعنی هنوز یکی از این
سه مرحله انجام نشده است.

### نصب روی گوشی و کامپیوتر

وقتی نشانی بالا برنامه را نشان داد (صفحه‌ی سبزرنگ «ثبت هزینه جدید»):

- **اندروید (کروم):** منوی سه‌نقطه ← **«نصب برنامه»** یا **«افزودن به صفحه اصلی»**.
- **ویندوز (Edge یا Chrome):** آیکون **نصب** کنار نوار آدرس ← **Install**.
  برنامه در منوی Start می‌آید و در پنجره‌ی خودش باز می‌شود.

در خود برنامه هم در **تنظیمات → راهنمای نصب** دکمه‌ی «نصب برنامه روی این دستگاه» ظاهر می‌شود.

> گزینه‌ی نصب فقط روی صفحه‌ی خودِ برنامه دیده می‌شود، نه روی صفحه‌ی README.

بعد از نصب، برنامه **بدون اینترنت** هم کار می‌کند.

### راه دوم — بدون اینترنت و بدون نصب

پوشه‌ی `app/` را روی کامپیوتر کپی کنید و فایل `app/index.html` را با Chrome یا Edge باز کنید.
همه‌چیز کار می‌کند و اطلاعات ذخیره می‌شود؛ فقط امکان «نصب به‌عنوان برنامه» در این حالت وجود ندارد.

---

## اطلاعات کجا ذخیره می‌شود؟

به‌صورت پیش‌فرض، اطلاعات **فقط روی همان دستگاه** ذخیره می‌شود و هیچ‌جا ارسال نمی‌گردد.
یعنی هزینه‌های ثبت‌شده روی گوشی، خودبه‌خود روی کامپیوتر دیده نمی‌شوند.

دو راه برای اشتراک اطلاعات هست:

**راه ساده (بدون تنظیمات):** تنظیمات ← تهیه فایل پشتیبان ← فایل را به دستگاه دیگر ببرید ←
آنجا بازیابی از فایل. پیشنهاد می‌شود ماهی یک‌بار پشتیبان بگیرید، حتی اگر همگام‌سازی روشن باشد.

**راه خودکار:** همگام‌سازی را روشن کنید (پایین‌تر توضیح داده شده).

---

## راه‌اندازی همگام‌سازی بین دستگاه‌ها

با این کار هزینه‌ای که روی یک گوشی وارد می‌شود، تا حدود یک دقیقه بعد روی بقیه‌ی
دستگاه‌ها هم می‌آید. برنامه از **Cloud Firestore** گوگل استفاده می‌کند که برای این
حجم کار کاملاً رایگان است (نیازی به وارد کردن کارت بانکی نیست).

### مرحله ۱ — ساخت پروژه (یک‌بار، حدود ۵ دقیقه)

۱. به <span dir="ltr">https://console.firebase.google.com</span> بروید و با حساب گوگل وارد شوید.
۲. **Create a project** ← یک نام دلخواه (مثلاً `hesab-ketab`) ← Google Analytics را
   **خاموش** کنید ← Create project.
۳. از منوی راست: **Build → Firestore Database → Create database** ←
   حالت **Production mode** ← نزدیک‌ترین منطقه (مثلاً `europe-west`) ← Enable.
۴. در همان صفحه، تب **Rules**: محتوای فایل `firestore.rules` این پروژه را کپی کنید،
   جایگزین متن موجود کنید و **Publish** را بزنید.
۵. از منوی راست: **Build → Authentication → Get started** ← تب **Sign-in method** ←
   **Anonymous** را انتخاب و **Enable** کنید ← Save.
۶. روی چرخ‌دنده‌ی بالای منو ← **Project settings** ← پایین صفحه در بخش *Your apps*
   روی آیکون **`</>`** (Web) بزنید ← یک نام بدهید ← Register app.
   حالا دو مقدار به شما نشان داده می‌شود که لازم دارید:
   - **`apiKey`** (با `AIza` شروع می‌شود)
   - **`projectId`**

### مرحله ۲ — روشن کردن روی دستگاه اول

در برنامه: **تنظیمات ← همگام‌سازی بین دستگاه‌ها ← راه‌اندازی همگام‌سازی**

- `apiKey` و `projectId` را بچسبانید.
- دکمه‌ی **«ساخت کد جدید»** را بزنید تا کد خانواده ساخته شود.
- **این کد را جایی یادداشت کنید** (در فایل پشتیبان ذخیره نمی‌شود).
- **روشن کردن** را بزنید.

### مرحله ۳ — بقیه‌ی دستگاه‌ها

روی هر گوشی یا کامپیوتر دیگر، همان سه مقدار را وارد کنید:
همان `apiKey`، همان `projectId` و **همان کد خانواده**.
چند ثانیه بعد، همه‌ی هزینه‌ها روی آن دستگاه هم می‌آید.

### چند نکته

- **کد خانواده مثل رمز عبور است.** هر کسی آن را داشته باشد می‌تواند هزینه‌ها را
  ببیند و تغییر دهد. آن را در گروه‌های عمومی نگذارید.
- **بدون اینترنت هم می‌توانید هزینه وارد کنید.** روی همان دستگاه ذخیره می‌شود و
  به‌محض وصل شدن، خودکار به بقیه می‌رسد.
- **اگر دو نفر هم‌زمان یک هزینه را ویرایش کنند**، آخرین ویرایش باقی می‌ماند.
  برای همین ساعت دستگاه‌ها باید درست باشد.
- همگام‌سازی هر ۴۵ ثانیه و همچنین هنگام باز کردن برنامه انجام می‌شود؛ آنی نیست.
  دکمه‌ی «همگام‌سازی الان» هم برای وقتی است که عجله دارید.
- برای خاموش کردن: **تنظیمات ← همگام‌سازی ← خاموش کردن**. اطلاعات روی دستگاه می‌ماند.

## ساختار پروژه

```
app/
  index.html            صفحه و ساختار برنامه
  styles.css            ظاهر (تم روشن/تیره، راست‌چین، چاپ)
  app.js                منطق برنامه: ثبت، فیلتر، گزارش، پشتیبان
  sync.js               همگام‌سازی با Firestore (بدون SDK، از راه REST)
  jalali.js             تبدیل تاریخ شمسی ↔ میلادی
  sw.js                 سرویس‌ورکر برای کارکرد آفلاین
  manifest.webmanifest  معرفی برنامه برای نصب روی اندروید و ویندوز
  icons/                آیکون‌های برنامه
firestore.rules         قوانین دسترسی پایگاه داده (در فایربیس Publish شود)
tools/
  make-icons.js         ساخت دوباره‌ی آیکون‌ها (node tools/make-icons.js)
.github/workflows/
  pages.yml             انتشار خودکار روی GitHub Pages
```

بدون هیچ کتابخانه‌ی بیرونی و بدون مرحله‌ی build نوشته شده است.
